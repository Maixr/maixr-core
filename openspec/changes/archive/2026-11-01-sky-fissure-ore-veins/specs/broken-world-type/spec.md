# Spec Delta

## MODIFIED Requirements

### Requirement: 空域浮岩

空域 SHALL 只生成**一类**浮岩：「天隙矿脉」。旧版**陨石团簇分支 MUST NOT 存在**
（v7 起天空石改为矿脉宿主材质，不再以独立椭球团簇生成）。
矿脉 origin 的 y 范围 SHALL 为 **-50~300**（`VEIN_MIN_Y=-50`、`VEIN_MAX_Y=300`）。

**「天隙矿脉」**按 **4x4 区块单元网格**生成（每单元一道，约每 16 区块一道）：
一道细长裂隙石脉，长 96~224 格。主脉走向随机水平方向、每步方向扰动 ±5~15°
且整体摆动限幅 ±~20°（轻弯不折腾，长脉 MUST NOT 蜷曲成一团），origin 居中
（脉向两侧延伸各约半长）；截面为扁椭球（水平半径 2~4、垂直约其七成，MUST NOT 是纯平面）
沿程相干起伏（厚薄呼吸），上下两侧随机挂 1~3 格小碎片（两侧挂屑），低概率 ±1
格横向错台（偶发错台），两端楔形收尖（半径逐级不跳级、末端单块须尖，
MUST NOT 齐头截断；不生成支脉，单一笔直主脉）。

**宿主按矿脉 origin 的 y 分带决定，整脉统一、MUST NOT 混拼**（v7 替换 v6 的
"整脉 70/30 随机"）：

| origin y | 宿主 |
|---|---|
| `-50 ≤ y ≤ 8`（`DEEPSLATE_ZONE_MAX_Y`） | `minecraft:deepslate` **100%** |
| `8 < y < 180`（`SKY_STONE_MIN_Y`） | `minecraft:stone` **100%** |
| `180 ≤ y ≤ 300`（`VEIN_MAX_Y`） | `minecraft:stone` 85% / `ae2:sky_stone_block` 15%（`SKY_STONE_SHARE = 0.15`） |

深板岩带内的矿脉 MUST 全部为深板岩，MUST NOT 出现 stone 或 sky_stone 脉。
高空带的天空石脉 MUST 沿用同一套裂隙形态与矿囊机制（天空石是宿主的第三种
材质，MUST NOT 被实现为独立装饰分支/圆球团簇）。
`ae2:sky_stone_block` 未注册（未安装 AE2）时，该脉 SHALL **回退为
`minecraft:stone`**，MUST NOT 整条消失或放置空气。

脉内沿径嵌 6~14 处 r=1~3 矿囊，矿囊为**矿石方块**（MUST NOT 使用
粗矿块 `raw_*_block`），**每个矿囊独立抽矿种、按稀有度加权**（铁铜常见、
金稀、钻石与模组稀有矿更稀）——同一条石脉上 MUST 允许并存多种矿石。
矿囊与宿主匹配：deepslate 脉刷深板岩矿石变体（无变体时回退常规矿石），
stone 脉与 sky_stone 脉刷常规矿石（天空石脉 MUST NOT 引入专属矿种）。

矿脉几何与宿主分带 MUST 由「世界种子 + 单元坐标」确定性决定，且**跨区块协作放置**：
每个区块 SHALL 只放置落在自己可写范围（中心区块 ±1 区块）内的片段，
相邻区块的片段 MUST 无缝拼合（无断面、无缺失段）；同种子同坐标的
放置结果 MUST 一致（与区块求值顺序无关，写入幂等）。
MUST NOT 在矿脉放置期间使用 `ctx.random()` 决定形态、宿主或矿种。

矿种候选 MUST 由粗矿块候选清单映射为对应矿石方块，并在首次使用时按注册表
过滤：未安装模组或无对应矿石方块的候选不进池。
浮岩 ONLY 在主世界为破碎或空岛世界类型（及 `maixr:overworld_broken` 维度）
时生成。裂隙与矿囊只往空气放置，MUST NOT 覆盖已有地形（含天空结构方块）。

#### Scenario: 未安装模组的矿石自动剔除

- **WHEN** 矿种候选映射后的矿石方块所属模组未安装，或该候选不存在对应矿石方块
- **THEN** 该候选不进入池子，世界不会出现空气或粗矿块

#### Scenario: 未安装 AE2 时天空石脉回退

- **WHEN** 高空带被抽中为 sky_stone 宿主，但注册表查不到 `ae2:sky_stone_block`
- **THEN** 该脉以 `minecraft:stone` 整条生成，不出现空气段，也不整条缺失

#### Scenario: 默认世界类型不生成浮岩

- **WHEN** 主世界使用原版噪声生成器
- **THEN** 空域不生成任何浮岩

#### Scenario: 不再生成陨石圆球

- **WHEN** 在破碎世界的新生成区域观察空域
- **THEN** MUST NOT 出现外壳 `ae2:sky_stone_block`、内核
  `ae2:smooth_sky_stone_block` 的椭球团簇；天空石只以细长矿脉形态出现

#### Scenario: 天隙矿脉形态

- **WHEN** 生成一道天隙矿脉
- **THEN** 可观察到细长裂隙状石脉（非圆球/椭球），长 96~224 格量级
  （跨约 6~14 个区块）：主脉走向接近直线，截面为有厚度的扁椭球
  （非纯平面），厚度沿程变化且两壁参差，上下两侧均有挂屑，
  两端楔形渐变收尖，无支脉分叉

#### Scenario: 矿脉跨区块无缝拼合

- **WHEN** 一道天隙矿脉跨越多个区块（必然——长度 96~224 格）
- **THEN** 相邻区块各自放置的片段拼合后 MUST 连续：无齐头平整截断、
  无缺失段、无重复冲突；任一区块缺失或后生成不影响最终形态
  （写入幂等、几何由单元种子唯一决定）

#### Scenario: 同种子确定性（按矿脉高度带判定）

- **WHEN** 同一种子两次全新生成同一区域，逐区块比对 section 调色板
- **THEN** **矿脉实际占据的高度带（y ≥ 180）** MUST 逐位一致；
  y < 180 的低空带允许存在与矿脉无关的差异（流体流动、深暗之域等原版
  生成过程的固有漂移），这些差异 MUST NOT 计入本场景的失败判定。
  判定口径：按 section-Y 分组统计差异，高位带差异数为 0 即通过
  （实现见 `_tools/verify/chunk_diff_by_y.py`）。

#### Scenario: 宿主按高度分带

- **WHEN** 在不同高度生成天隙矿脉
- **THEN** origin y ≤ 8 的脉通体为深板岩且矿囊为深板岩矿石变体
  （如 `deepslate_iron_ore`）；8 < origin y < 180 的脉通体为石头；
  180 ≤ origin y ≤ 300 的脉为石头或天空石（按 15% 抽取）；
  任一矿脉内部不出现族群混拼

#### Scenario: 深板岩带不出现石头脉

- **WHEN** 检查 origin y ≤ 8 的多道矿脉
- **THEN** 全部为深板岩，MUST NOT 观察到 `minecraft:stone` 或
  `ae2:sky_stone_block` 作宿主

#### Scenario: 高空天空石脉

- **WHEN** 在 origin y ≥ 180 的高空检查多道矿脉
- **THEN** 可观察到整脉由 `ae2:sky_stone_block` 构成的矿脉，形态与石头矿脉
  一致（细长、两壁参差、两端尖灭），且脉内仍有矿石矿囊；不出现天空石圆球团簇

#### Scenario: 矿囊产出矿石而非粗矿块

- **WHEN** 玩家发现并采掘天隙矿脉中的矿囊
- **THEN** 看到与采到的是矿石方块（如 `minecraft:iron_ore`），
  整条矿脉中不出现 `raw_*_block`

#### Scenario: 同一石脉混生多种矿石

- **WHEN** 检查一条天隙矿脉上的多个矿囊
- **THEN** MUST 能观察到不同矿囊使用不同矿种（同一脉上可同时出现铁、铜、
  金、钻石等），而非整条脉单一矿种
